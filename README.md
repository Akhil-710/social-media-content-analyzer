# Social Media Content Analyzer

A web-based application that analyzes social media content from PDF and image files and provides actionable suggestions to improve engagement, readability, and content quality.

## 🚀 Live Demo

https://social-media-content-analyzer-4diz.onrender.com/

## 📂 Source Code

The complete application source code is available inside the `social-media-content-analyzer` directory.

## 🛠️ Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- PyMuPDF
- Tesseract OCR
- Pillow
- pytest

## ✨ Features

- PDF and image upload
- Drag-and-drop file upload
- PDF text extraction
- OCR for images and scanned PDFs
- Content analysis
- Engagement scoring
- Readability scoring
- Hook scoring
- Actionable improvement suggestions
- Error handling and loading states
